Simplex BFT ทำงานยังไง?
  • Byzantine Fault Tolerant — ทนต่อ node ที่ล้มเหลวหรือ malicious ได้ 1/3
  • Deterministic finality — เมื่อ tx ถูก confirm แล้ว ไม่สามารถย้อนกลับได้
  • No reorgs — ไม่มี chain reorganization เหมือน PoW/PoS

จ่าย Gas Fee ด้วย Stablecoin — ไม่ต้องถือ ETH
Fee AMM — pay gas in any supported USD stablecoin
INNOVATION
ปัญหาของ Ethereum / Base
  • ต้องถือ ETH สำหรับ gas fee — แม้จะอยากจ่ายด้วย USDC
  • User ต้องซื้อ ETH ก่อน → ซับซ้อนสำหรับ non-crypto users
  • Agent ต้องจัดการ ETH balance แยกจาก USDC — ยุ่งยาก
ทางออกของ Tempo: Fee AMM
  • จ่าย gas fee ด้วย USDC, USDT, pathUSD — stablecoin ใดก็ได้
  • ไม่ต้องถือ ETH เลย — UX ง่ายเหมือนใช้แอปธนาคาร
  • Agent จัดการเงินสกุลเดียว — ไม่ต้อง swap ETH/USDC
ตัวอย่าง: Agent จ่ายค่า API
Agent
เรียก API → ได้ 402 Payment Required → จ่าย $0.005 USDC
Tempo Fee AMM
✅ หัก 0.005 USDC จาก wallet → จ่าย gas + ค่า API ใน tx เดียว → ได้ข้อมูลกลับ
💡
Fee AMM = Automated Market Maker สำหรับ gas fee — convert stablecoin → gas อัตโนมัติ behind the scenes

Best practices for autonomous shopping
⚠ SAFETY
✅ DO — ควรทำ
  • ตั้ง spending cap รายวันใน wallet (เช่น $5/day)
  • ตรวจสอบ transaction บน explorer ทุกครั้ง

  • แยก wallet สำรองสำหรับการทดลอง
⚠️ WATCH — ระวัง
  • อ่าน refund policy ของ service ใหม่ก่อนใช้

  • เก็บ PIN + backup phrase ในที่ปลอดภัย
❌ AVOID — ห้ามทำ
  • ใช้ wallet หลักจ่ายรายวัน — แยก wallet สำรองไว้
  • เผย PIN / wallet address ในที่สาธารณะ
